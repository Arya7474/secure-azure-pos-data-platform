# Naming Convention

## General Pattern
`<org>-<project>-<service>-<env>-<region>-<nn>`

Because this is a personal portfolio project, a simplified version will be used.

## Example Prefix
`sz-pos-dev`

## Example Resource Names
- Resource Group: `rg-sz-pos-dev`
- VNet: `vnet-sz-pos-dev`
- Storage Account: `stszposdev01`
- Key Vault: `kv-sz-pos-dev`
- Data Factory: `adf-sz-pos-dev`
- Databricks: `dbw-sz-pos-dev`
- SQL Database Server: `sql-sz-pos-dev`
- SQL Database: `sqldb-pos-control-dev`
- Synapse Workspace: `syn-sz-pos-dev`
- Dedicated SQL Pool: `dwh_pos_dev`
- Log Analytics: `log-sz-pos-dev`

## Tagging Standard
All resources should include:
- `Project = SecureAzurePOS`
- `Environment = Dev`
- `Owner = Souvik`
- `Purpose = Portfolio`
- `CostCenter = Learning`
