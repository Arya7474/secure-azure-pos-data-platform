# Phase Plan

## Phase 0 - Project foundation
Create repository structure, core documentation, conventions, and delivery approach.

## Phase 1 - Source data and dimensional model
Define sample source files, data dictionary, and warehouse target model.

## Phase 2 - Architecture and security design
Create architecture diagram, network design, security model, and service interactions.

## Phase 3 - Infrastructure as Code
Prepare modular Bicep templates and deployment scripts.

## Phase 4 - Network and secure resource deployment
Deploy VNet, subnets, private endpoints, DNS zones, and core resources.

## Phase 5 - Identity and access
Configure managed identities, RBAC, Key Vault access, and service authentication patterns.

## Phase 6 - Data lake and control DB
Configure storage containers, folder structure, control tables, and audit model.

## Phase 7 - Databricks transformations
Build notebooks for bronze, silver, and curated output.

## Phase 8 - ADF orchestration
Build pipelines, datasets, linked services, parameters, and scheduling.

## Phase 9 - Logic App integration
Add notification or approval flow integration.

## Phase 10 - Synapse warehouse load
Load dimensions and facts into dedicated SQL pool.

## Phase 11 - CI/CD
Prepare Azure DevOps pipelines for infra and data assets.

## Phase 12 - Monitoring and operations
Add logs, alerts, runbooks, and operating checklist.
